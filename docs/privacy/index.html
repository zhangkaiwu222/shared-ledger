一起算 · 隐私政策

更新日期：2026年10月26日 · 生效日期：2026年10月26日

「一起算」是一款面向家庭、情侣与合租场景的共同记账工具。我们非常重视你的隐私。请仔细阅读本政策。

1. 我们收集哪些数据

当前版本默认将以下数据仅保存在你的设备本地：

  • 账本名称、成员昵称
  • 支出金额、分类、备注、付款人、分摊结果
  • 订阅状态（是否解锁 Pro；正式上线后由 Apple 管理购买凭证）

我们不收集：姓名实名、手机号、通讯录、精确位置、相册内容浏览、广告标识符（IDFA）。

2. 数据使用目的

  • 在设备上展示账单、计算分摊与催款卡片
  • 提供本月报表等 Pro 功能
  • 处理 App Store 订阅（由 Apple 完成扣款与收据校验）

3. 存储方式与时长

账单与成员信息存储在本机应用沙盒中。你可在设置中「清空并重新开始」删除本地数据。卸载应用通常会清除本地数据。

4. 第三方与 SDK

当前正式功能不集成统计分析、广告、社交登录等第三方 SDK。订阅支付走 Apple App Store / StoreKit。若未来新增第三方服务，我们将更新本政策并在 App 内提示。

5. 系统权限

  • 分享 / 相册（如启用保存图片）：仅用于导出催款卡片，便于发送给家人或室友。不会自动扫描相册。

6. 你的权利

你可以随时在应用内删除账单数据，或卸载应用。如需协助，请通过下方联系方式与我们联系。

7. 儿童隐私

本应用不面向 13 岁以下儿童，也不主动收集儿童个人信息。
